## 📲 What can I do?

I’m a dynamic movie discovery and planning app and I can help you:

- 🔥 Explore **Top-Rated Movies**
- 🔍 **Search** by movie title
- 🎞️ Dive into **Detailed Movie Info** (cast, rating, genres, runtime, and more)
- 👯‍♀️ **Create & Join Viewing Parties** with your friends

I’m built with:

- **Rails API** – powering my backend brain  
- **React** – giving me a sleek and interactive face  
- **VCR** – mocking external API calls for tests  
- **RSpec** – making sure everything I do works smoothly

## 🚀 Getting Started

### 🔧 Installation

Wanna get me running locally? Here’s how:

1. **Clone the repository**
   ```bash
   git clone git@github.com:Jonathan-Atkins/Watch_Dogs.git
   cd Watch_Dogs
   ```

2. **Install dependencies**
   ```bash
   bundle install
   ```

3. **Set up the database**
   ```bash
   rails db:create
   rails db:migrate
   ```

4. **Start the Rails server**
   ```bash
   rails server
   ```

5. **Open your browser** and visit:
   ```
   http://localhost:3000
   ```

## 🌐 Features

✨ **Movie Search**  
Find movies by title and view ratings, summaries, release dates, genres, cast, and more.

🎬 **Top-Rated Movies**  
Quick access to the highest-rated films from the TMDB database.

👯 **Viewing Parties**  
Create and invite others to virtual watch parties. Share movie details and enjoy movies together!

## 🧪 Testing

I’m fully tested using RSpec and VCR.

To run the test suite:

1. Make sure dependencies are installed:
   ```bash
   bundle install
   ```

2. Run tests:
   ```bash
   rspec
   ```
