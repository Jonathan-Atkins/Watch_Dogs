## 📲 What is WatchDogs?

WatchDogs is a dynamic movie discovery and planning app that lets you:

- 🔥 Explore **Top-Rated Movies**
- 🔍 **Search** by movie title
- 🎞️ Dive into **Detailed Movie Info** (cast, rating, genres, runtime, and more)
- 👯‍♀️ **Create & Join Viewing Parties** with your friends

Built with:

- **Rails API** – for fast and robust backend functionality  
- **React** – for a sleek and interactive front-end experience  
- **VCR** – to mock external API calls for testing  
- **RSpec** – to ensure everything works like a charm

## 🚀 Getting Started

### 🔧 Installation

Follow these steps to set up WatchDogs locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/watchdogs.git
   cd watchdogs
   ```

2. **Install dependencies**
   ```bash
   bundle install
   ```

3. **Set up the database**
   ```bash
   rails db:create
   rails db:migrate
   ```

4. **Start the Rails server**
   ```bash
   rails server
   ```

5. **Open your browser** and visit:
   ```
   http://localhost:3000
   ```

## 🧪 Testing

WatchDogs is fully tested using RSpec and VCR.

To run the test suite:

1. Make sure dependencies are installed:
   ```bash
   bundle install
   ```

2. Run tests:
   ```bash
   rspec
   ```

## 📚 Technologies Used

- **Ruby on Rails (API only)** – Handles business logic and external movie data integration  
- **React** – Delivers a dynamic and user-friendly front-end  
- **VCR** – Stubs API requests for reliable and fast testing  
- **RSpec** – BDD-style test framework for Ruby/Rails
